## Codebase Patterns
- Frontend is Vite + React + TypeScript in `frontend/` directory
- Tests use Vitest + React Testing Library, run with `npm test`
- Build: `npm run build`, Typecheck: `npm run typecheck`
- Existing tests: 6 test files, 46 tests all passing
- Shadcn components go in `frontend/components/ui/` with `lib/utils.ts` providing `cn()`
- Tailwind config: content paths `['./index.html', './src/**/*.{ts,tsx}']`
- Shadcn uses `~` path alias (defined in tsconfig paths as `"~/*": ["./*"]`) for `~/components/ui/*` and `~/lib/utils`
- Vite config must include `resolve.alias` for `~` to work at runtime (not just compile time)
- `@tailwind` directives must be at top of `frontend/src/index.css` (before existing plain CSS)
- Shadcn adds radix-ui primitives as peer deps
- Vite config uses `import.meta.url` / `fileURLToPath` for the `~` alias (not `__dirname`)
