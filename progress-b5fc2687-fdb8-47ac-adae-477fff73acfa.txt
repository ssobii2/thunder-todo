## Codebase Patterns
- Shadcn UI components are in `frontend/components/ui/` (NOT `frontend/src/components/ui/`)
- `~/components` alias maps to `frontend/components/` (tsconfig baseUrl = frontend, paths = { "~/*": ["./*"] })
- `~/lib/utils` maps to `frontend/lib/utils.ts` (contains `cn()` for Tailwind class merging)
- All Shadcn components use `class-variance-authority` (CVA) for variant management
- Button variants: default, destructive, outline, secondary, ghost, link; sizes: default, sm, lg, icon
- Tests live in `frontend/src/__tests__/`
- Radix primitives used: `@radix-ui/react-checkbox`, `@radix-ui/react-slot`
- Icons from `lucide-react`
- Badge renders as a `<div>` with CVA variants (default, secondary, destructive, outline)
- When refactoring class-based "active" styling to Shadcn components, update tests to check for element type (div vs button) instead of CSS class
